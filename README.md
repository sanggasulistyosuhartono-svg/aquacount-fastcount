# AquaCount FastCount Gabungan

Versi ini menggabungkan:
1. FastCount PL
2. FastCount Bacteri / Colony Counter

## File utama
- app.py
- requirements.txt

## Cara Upload ke GitHub
1. Backup file app.py lama.
2. Upload app.py baru ini ke repository Streamlit.
3. Pastikan requirements.txt sudah ikut di-update.
4. Commit perubahan.
5. Streamlit akan otomatis redeploy.

## Catatan
Pada mode TCBS Vibrio, titik merah/unclassified tidak ditampilkan dan tidak dihitung.
Yang dihitung hanya koloni kuning dan hijau.
